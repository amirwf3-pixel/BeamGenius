# BeamGenius — Phase 2A/2B/2C/2D/2E Source Verification Matrix & Repository Audit

## 1. Governance & Source Hierarchy

1. **Primary Engineering Methodology Source:**
   Davood Mostofinejad — *Reinforced Concrete Structures*, Volume 1 (used for calculation methodology, mechanics, design sequences, and isolated reference regression examples).
2. **Governing Iranian Code Source:**
   Iranian National Building Regulations — **Mabhas 9** (governing mandatory code requirements, resistance factors, limits, detailing rules, applicability conditions, and compliance checks).
3. **Conflict & Production Gate Rule:**
   - Where Mostofinejad Vol. 1 and Mabhas 9 differ on a mandatory Iranian requirement, **Mabhas 9 governs**.
   - Production code (`JurisdictionMode.MABHAS_9_COMPLIANCE`) may execute **ONLY** rules with `Status = VERIFIED`, `Type = CODE_RULE`, and an explicit record in `docs/VERIFIED_RULES.md`.
   - OCR text is a navigation aid only; no unverified OCR token or remembered ACI/CSA value may be converted into an executable rule.
   - Missing source pages/clauses are **never invented**; rules lacking verified source pages remain explicitly `VERIFY_PENDING` / `UNVERIFIED_RULE_BLOCKED`.
